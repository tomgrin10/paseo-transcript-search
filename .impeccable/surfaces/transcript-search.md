# Transcript search surface

Mode: Operate. This extends the existing agents-history surface inside Paseo; native settings use the host's settings components. No replacement visual world or raster work is in scope.

## Direction contract

THESIS: Find a previous statement quickly from the keyboard, including conversations archived by the host. Retain the established native interface instead of introducing a separate application shell.

OWN-WORLD: Paseo semantic surface, foreground, border, accent, and status colors; platform sans typography; Lucide icons. Inherit the source's workspace/session grouping. Let Paseo render headers, settings rows, scrolling, and responsive navigation.

STORY: Open the Command Center from this host, select search, type text into the focused field, and inspect snippets. Open the matching session, confirming restoration for archived sessions. Hide each plugin's sidebar entry in its native Display settings while keeping its direct surface command.

FIRST VIEWPORT: Host navigation at left on desktop; a focused full-width search field at the top of the surface, compact filters below, coverage status, then matching workspace/session rows. Native Display has a single Show in sidebar switch. Narrow layouts wrap filters and use the host's compact navigation.

FORM: Code-led adaptation of an established world; no new form selection or seed applies. Preserve source visuals and host components.

FINISH: Verify real search, empty results, and hidden-sidebar keyboard access. Review desktop and narrow screenshots, document the inherited system, and preserve attribution. No shipping raster assets are created.
